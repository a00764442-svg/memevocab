# MemeVocab: прототип поиска (этап 0)

Проверяет на реальных данных: сколько немецких слов удаётся найти на настоящих мемах Reddit с подтверждённым точным совпадением через OCR.

## Запуск
1. Получите одобрение Reddit API (некоммерческое использование), создайте app типа "script"/"web" и возьмите client id и secret.
2. `npm install`
3. `REDDIT_CLIENT_ID=... REDDIT_CLIENT_SECRET=... REDDIT_USER_AGENT="memevocab-prototype/0.1 by u/ВАШ_НИК" npm start`
4. Результат: вывод в консоли и `report.json` (кандидаты / confirmed / needs_review на каждое слово).

Проверки: `npm test` (логика совпадения, без сети), `npm run typecheck`.

## Правила совпадения (src/match.ts)
- confirmed: точный токен (регистр и ß свёрнуты), уверенность OCR >= 80.
- needs_review: низкая уверенность, перенос через дефис, расстояние 1 (возможная ошибка OCR).
- Другие словоформы (verschläft) и подстроки (schlafen в verschlafen) не совпадают. Умлауты не сворачиваются.

## Что нужно решить с Reddit
- Поиск Reddit работает по заголовкам, не по тексту на картинке. Поэтому берутся результаты поиска и топ сообществ, а решает OCR.
- Картинки скачиваются в память только для OCR и на диск не пишутся. Допустимость этого и показа картинок в приложении укажите в заявке на доступ и дождитесь ответа.
- Список сообществ (SUBREDDITS) проверьте вручную. NSFW-посты пропускаются.
